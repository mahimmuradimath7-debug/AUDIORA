# Asset provenance

- `frontend/assets/*.svg`: original geometric artwork and brand marks made for this Audiora project. No external podcast covers, logos, photographs or font files are bundled.
- `media/audiora-preview.mp3`: original synthesized ambient composition generated by `tools/generate-demo.cjs`. It contains no third-party samples and no speech. Approximately 30 seconds; small MP3 encoder padding is normal.
- `docs/preview-desktop.png`, `docs/preview-mobile.png`: screenshots of this implementation captured by its own browser tests.
- Seed episode titles, show identities and studio/host names are fictional demonstration material, not claims of relationships with real creators.
- The running website uses installed system fonts. Their appearance and Indic-script shaping may differ across platforms.

Optional development dependencies retain their own licences: Playwright, axe-core tooling, Prettier and lamejs. Their code is obtained through `npm ci`, not copied into this archive. The encoder is development-only; MP3 output does not require shipping its JavaScript library to listeners. Check the installed package licence files before redistributing development tooling.

The requested Audiora name has not undergone trademark or domain-availability clearance. Use your own authorised recordings for a real catalogue and commission native-speaker editorial review before publication.
